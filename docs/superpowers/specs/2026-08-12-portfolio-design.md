# 포트폴리오 디자인 스펙

- 날짜: 2026-08-12
- 상태: 사용자 승인 완료 (구현 전)

## 목적과 타겟

국내 **데이터/AI 직군 취업**용 포트폴리오. 세부 직무는 데이터 사이언티스트, ML/AI 엔지니어, 데이터 분석가, LLM/NLP 특화를 모두 커버하는 "통계학 기반 풀스펙트럼" 포지셔닝. 표기 언어는 **한국어 중심**, 기술 용어는 영문 그대로 사용.

핵심 차별점: 학부생 신분의 공동 1저자 등재 논문(KJAS)과 LLM 파인튜닝·추론 실무 경험. 통계적 엄밀함 + LLM 연구 경험의 결합을 전면에 내세운다.

## 포트폴리오 사이트

### 기술 스택

순수 HTML + CSS + 최소한의 바닐라 JS. 프레임워크·빌드 도구 없음.

근거: 단일 페이지에 프레임워크는 과잉. 빌드 없는 정적 파일이 유지보수(내용 수정 = HTML 편집 후 push)와 인쇄 품질 제어에 가장 유리.

### 디자인 방향 (A×C 절충안, 목업 승인됨)

- **기조(A: 미니멀 문서형)**: 흰 배경, 산세리프, 검정 위주의 단정한 타이포그래피, 이력서에 준하는 밀도
- **구조(C: 데이터 모던)**: 카드 레이아웃, 기술 태그, 절제된 포인트 컬러 1색 (시안: 네이비 `#345995`, 구현 시 조정 가능)
- 콘텐츠로 꽉 채운 벽(A의 단점)과 가벼운 인상(C의 단점)을 모두 피한다

### 페이지 구성 (단일 페이지, 상→하)

1. **헤더** — 이름, 한 줄 소개, 연락처(이메일 · GitHub · Google Scholar · velog)
2. **About** — 2~3문장. 통계학 기반 + LLM 연구 경험이라는 차별점 서술
3. **Featured Projects** — 4개 클릭 확장 카드
   - 접힌 상태: 제목 + 한 줄 요약 + 성과 뱃지(게재·진행중 등)
   - 펼친 상태: **문제 → 접근 → 성과(수치) → 본인 기여도** + 기술 태그 + GitHub/논문 링크
   - 대상: LLMdetector(KJAS 공동 1저자), HFRL/SurvLLM(진행중), TSTF(IEEE Access 기여), dash(대시보드)
4. **Publications** — 논문 2편 정식 인용, 본인 이름 강조
5. **Skills** — 언어(Python·R·Julia·SQL·SAS·C#) / ML·DL(PyTorch·Transformers·vLLM 등) / 도구, 분류형 표기
6. **Education & Certificates** — 전북대 통계학 학사(2026.08), BAE, SQLD

### 인터랙션

- 카드 **클릭** 확장 (hover 확장 금지 — 레이아웃 출렁임, 모바일 미동작)
- **Affordance 필수** (사용자 지적 사항): 회전하는 펼침 화살표(▸→▾), hover 시 배경 변화, "자세히" 힌트 텍스트. 클릭 가능하다는 것이 첫눈에 보여야 한다

### 인쇄 (PDF 제출 시나리오)

- `@media print`: 모든 카드 강제 펼침 → 제출본에 전체 내용 포함
- A4 세로 기준 여백, 카드 중간에서 페이지가 잘리지 않도록 `break-inside: avoid`
- 링크는 URL 병기, 배경색·장식 제거 (잉크 절약형)

## 리포 README 정비 (4개)

공통 구조: **개요(무슨 문제) → 방법(어떻게) → 결과(수치·산출물) → 리포 구조 안내 → 실행/재현 방법**

- 리포 description·topics 정리 (예: HFRL "Fine Tuning Test" → 실제 연구 내용, dash "some dashboard page" → 구체적 설명)
- 논문 리포(LLMdetector, TSTF): 논문 링크 + 본인 기여 명시 추가
- **위임 옵션**: 학습 산출물(데이터셋·모델·로그·체크포인트)이 원격 서버에 있으므로, 해당 서버에서 실행되는 클로드 에이전트가 리포 README 정비를 직접 수행하는 것이 더 정확할 수 있음 (특히 HFRL/SurvLLM). 구현 계획에서 리포별로 로컬 작업 / 원격 위임을 구분하고, 원격 위임분은 해당 에이전트에게 전달할 작업 지시문을 산출물로 만든다. 원격 서버는 SSH 불가, 사용자가 원격 데스크탑으로 접속.
