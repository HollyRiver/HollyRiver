## 결정

shields.io 배지를 자체 제작 애니메이션 SVG 배너로 교체한다.

- **구성**: 원라인 배너 780×68 — "포트폴리오"(19px 볼드) + "프로젝트 상세, 스킬, 자격 등 포함"(13.5px 회색) + 오른쪽 끝 정지 화살표(→, 액센트 색)
- **애니메이션**: 상단 3px 트랙 위로 빛줄기가 3.4s 주기로 흐름 (SVG 내장 CSS keyframes — GitHub `<img>` 렌더링에서도 동작)
- **화살표는 정지**: hover 반응은 GitHub README `<img>`에 마우스 이벤트가 전달되지 않아 구현 불가 → 사용자 확인 후 정지로 확정
- **다크모드**: `<picture>` + `prefers-color-scheme`로 라이트/다크 SVG 자동 전환
- **색상**: 포트폴리오 사이트 토큰과 통일 (액센트 #345995, 잉크 #1c1c1e)
